📦 Flexbox Self-Explained Tutorial

1. What is Flexbox?

Flexbox is a layout system in CSS that helps arrange items in a row or column. It uses a flex container and flex items.

display: flex;

7. Summary

  • display: flex → activates flexbox
  • flex-direction → row / column
  • justify-content → horizontal alignment
  • align-items → vertical alignment
  • flex-wrap → wrapping items
  • flex-grow → expanding items
