Bootstrap Container Tutorial

Understanding how containers work in Bootstrap

What is a Container?

In Bootstrap, a container is used to wrap your content. It provides proper alignment, spacing, and responsiveness.

Containers are the most basic layout element in Bootstrap and are required when using the grid system.

.container (Fixed Width)

The .container class creates a responsive fixed-width layout. Its width changes at different screen sizes (breakpoints).

Responsive Containers

Bootstrap also provides responsive containers like:

  • .container-sm
  • .container-md
  • .container-lg
  • .container-xl

These containers are fluid until a specific breakpoint, then become fixed-width.

This is .container-md — it behaves like fluid on small screens, and fixed width on medium and larger screens.

Nested Containers & Grid

Containers usually contain rows, and rows contain columns. You can also nest rows inside columns for more complex layouts.

Summary

  • .container → fixed width (responsive)
  • .container-fluid → full width
