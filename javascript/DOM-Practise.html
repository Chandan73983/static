Section 1: Introduction to DOM

DOM browser ka live map hai. HTML file static recipe hoti hai, DOM browser ke andar bani hui live dish hoti hai jise JavaScript change kar sakti hai.

Theory

DOM ka full form Document Object Model hai. Browser HTML ko read karke objects ki tree structure banata hai. Har tag ek node ban jata hai, jaise h1, p, button. JavaScript in nodes ko select, update, create aur delete kar sakti hai.

HTML vs DOM: HTML source code hai. DOM browser memory mein live structure hai. Agar JS se text badal diya, source file same reh sakti hai, lekin DOM aur screen update ho jaate hain.

Importance: Dynamic websites, validation, animations, buttons, modals, sliders, forms, dashboards sab DOM ke bina incomplete hain.

Section 2: Selecting Elements

getElementById()

Unique ID wale element ko select karta hai. Fast aur direct hota hai.

const title = document.getElementById("main-title");

getElementsByClassName()

Same class ke multiple elements ka live HTMLCollection deta hai.

const notes = document.getElementsByClassName("note");

getElementsByTagName()

Tag name se elements pick karta hai, jaise saare p tags.

const paras = document.getElementsByTagName("p");

querySelector()

CSS selector use karke first matching element deta hai. Modern projects mein bahut common.

const firstNote = document.querySelector(".note");
Practice: Ek card select karke uska border color change karo.

querySelectorAll()

CSS selector ke saare matching elements ka static NodeList deta hai. Is par forEach easy hota hai. 

document.querySelectorAll(".note").forEach(el => {
  el.style.fontWeight = "bold";
});

Section 3: Changing Content

Text aur HTML update karna DOM ka daily kaam hai. Bas difference samajhna important hai: HTML parse karna hai ya plain text dikhana hai?

Theory

innerHTML HTML tags ko parse karta hai. innerText visible text deta hai aur CSS visibility ka effect consider karta hai. textContent raw text content deta hai, hidden text bhi include ho sakta hai.

box.innerHTML = "<strong>Bold</strong>";
box.innerText = "Visible text";
box.textContent = "Fast plain text";

    Section 14: DOM Interview Questions

    50 common DOM interview questions with short Hinglish answers. Inhe revise karoge to theory aur practical dono clear rahenge.

    1. DOM kya hai? Browser ka live object tree jo HTML document represent karta hai.
    2. Node kya hota hai? DOM tree ka har part node hai: element, text, comment, document.
    3. Element node kya hai? HTML tag se bana node, jaise div, p, button.
    4. HTMLCollection kya hai? Live collection jo DOM change ke saath update ho sakti hai.
    5. NodeList kya hai? Nodes ki list; querySelectorAll static NodeList deta hai.
    6. getElementById kya karta hai? ID se single element select karta hai.
    7. querySelector kya karta hai? CSS selector se first matching element deta hai.
    8. querySelectorAll kya karta hai? CSS selector se saare matching elements deta hai.
    9. innerHTML kab use kare? Jab HTML markup inject karna ho; unsafe input se bachna hai.
    10. textContent kab better hai? Plain text ke liye, safer aur faster.
    11. innerText difference? Visible rendered text consider karta hai.
    12. classList kya hai? Classes add, remove, toggle, check karne ka API.
    13. Attribute methods? getAttribute, setAttribute, removeAttribute.
    14. data attributes kya hain? Custom info store karne ke liye data-* attributes.
    15. Event kya hai? User ya browser action, jaise click, input, submit.
    16. addEventListener ka fayda? Multiple listeners attach kar sakte hain, clean pattern hai.
    17. removeEventListener kab kaam karta hai? Same event, same function reference, same options ke saath.
    18. Event object kya deta hai? Target, key, coordinates, default behavior control jaisi info.
    19. event.target kya hai? Actual clicked/triggered element.
    20. event.currentTarget kya hai? Jis element par listener attached hai.
    21. Bubbling kya hai? Event target se ancestors tak upar jaata hai.
    22. Capturing kya hai? Event document se target ki taraf neeche jaata hai.
    23. stopPropagation kya karta hai? Event ko next ancestors tak jaane se rokta hai.
    24. preventDefault kya karta hai? Browser ka default action rokta hai.
    25. Event delegation kya hai? Parent listener se child events handle karna.
    26. Delegation useful kyu? Dynamic items aur performance ke liye.
    27. parentElement kya deta hai? Current element ka parent element.
    28. children kya deta hai? Direct child elements ka HTMLCollection.
    29. firstElementChild? Pehla child element.
    30. lastElementChild? Last child element.
    31. nextElementSibling? Same level ka next element.
    32. previousElementSibling? Same level ka previous element.
    33. createElement kya karta hai? Naya element node banata hai.
    34. append vs appendChild? append text aur multiple nodes accept karta hai; appendChild single node.
    35. prepend kya karta hai? Parent ke start mein content insert karta hai.
    36. remove kya karta hai? Element ko DOM se hata deta hai.
    37. replaceWith kya karta hai? Current node ko naye node/content se replace karta hai.
    38. Form value kaise read kare? input.value se.
    39. Form reload kaise roke? submit event mein preventDefault.
    40. Validation error kaise show kare? Error element ka textContent update karo.
    41. setTimeout kya hai? Delay ke baad function run karta hai.
    42. setInterval kya hai? Fixed interval par function repeat karta hai.
    43. clearTimeout? Pending timeout cancel karta hai.
    44. clearInterval? Repeating interval stop karta hai.
    45. DOMContentLoaded event? HTML parse hone ke baad fire hota hai.
    46. window.onload? Page assets including images load hone ke baad fire hota hai.
    47. Style change ka best way? Reusable CSS class toggle karna.
    48. Reflow kya hai? Browser layout recalculate karta hai.
    49. Repaint kya hai? Visual pixels redraw hote hain.
    50. DOM performance tip? Batch updates karo, unnecessary repeated layout reads avoid karo.
    Practice: In 50 mein se 10 questions ko apne words mein explain karo.
