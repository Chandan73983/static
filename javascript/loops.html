B. Classic Loop

for loop: Jab repeat count pehle se pata ho 🔢

`for loop` tab best hota hai jab hume pata ho ki loop kitni baar chalana hai. Jaise 1 se 10 tak numbers print karna, 5 students ke marks total karna, ya multiplication table banana. 

for (let i = 1; i <= 5; i++) {
  console.log("Round:", i);
}
Output yahan aayega...

1. Initialization

`let i = 1` se counter start hota hai. Ye loop ka starting point hai.

2. Condition

`i <= 5` check hota hai. True hai to loop body chalegi, false hai to loop stop.

3. Update

`i++` har round ke baad counter ko 1 se badhata hai.

Multiple Examples

// Reverse loop
for (let i = 5; i >= 1; i--) {
  console.log(i);
}

// Even numbers
for (let num = 2; num <= 10; num += 2) {
  console.log(num);
}

// Student marks total
let marks = [80, 90, 75, 88];
let total = 0;
for (let i = 0; i < marks.length; i++) {
  total += marks[i];
}
console.log(total);

Jab ek loop ke andar doosra loop hota hai, usse nested loop bolte hain. Real-life mein school timetable socho: outer loop days par chalega, inner loop periods par. Har day ke andar multiple periods. 

for (let day = 1; day <= 3; day++) {
  for (let period = 1; period <= 4; period++) {
    console.log("Day", day, "Period", period);
  }
}

Infinite Loop Warning ⚠️

Agar update miss ho jaye ya condition kabhi false na ho, loop rukega nahi. Browser hang ho sakta hai. Example: `for (let i = 1; i > 0; i++)` theoretically forever chalega.

C. Condition First

while loop: Jab repeat condition par depend kare ⏳

`while loop` tab use hota hai jab exact repeat count sure nahi hota. Jaise password attempts, game health, queue mein customers, ya jab tak battery 0 nahi hoti. 

let attempts = 1;

while (attempts <= 3) {
  console.log("Password try:", attempts);
  attempts++;
}
Point for loop while loop

D. Runs Once

do...while loop: Pehle kaam, baad mein condition ✅

`do...while` at least ek baar zaroor chalta hai, chahe condition false hi kyu na ho. Real-life: restaurant mein waiter menu ek baar zaroor dikhata hai, phir customer repeat order karna chahe to process continue hota hai. 

let balance = 0;

do {
  console.log("ATM screen ek baar show hogi");
  balance--;
} while (balance > 0);

while

Pehle condition check, phir code run. Condition false hai to zero times run.

do...while

Pehle code run, phir condition check. Condition false ho tab bhi one time run.

E. Values Loop

for...of loop: Array aur String ke values par loop 🍕

`for...of` iterable cheezon ke actual values deta hai: arrays, strings, sets, maps. Beginner ke liye arrays traverse karne ka clean tareeka hai. 

let foods = ["Pizza", "Dosa", "Momos"];

for (let food of foods) {
  console.log("Order item:", food);
}

for (let letter of "JS") {
  console.log(letter);

F. Keys Loop

for...in loop: Object properties par loop 🧾

Object ek real-world entity jaisa hota hai: student, employee, product. `for...in` object ke keys/properties par loop karta hai. 

let student = {
  name: "Aman",
  class: "10th",
  marks: 87
};

for (let key in student) {
  console.log(key + ": " + student[key]);
}

G. Loop Inside Loop

Nested Loops: Matrix, tables aur patterns ⭐

Nested loop ka matlab ek loop ke andar doosra loop. Outer loop rows control karta hai, inner loop columns control karta hai. Star patterns, multiplication tables, seating charts, matrices aur calendars mein nested loops kaafi useful hain. 

for (let row = 1; row <= 3; row++) {
  let line = "";
  for (let col = 1; col <= 4; col++) {
    line += "* ";
  }
  console.log(line);
}

Matrix

Rows aur columns print karne ke liye nested loop.

Tables

1 to 10 tables generate karne ke liye outer number, inner multiplier.

Pyramid

Spaces aur stars ke combination se pyramid pattern.

H. Control Flow

Loop Control Statements 🛑

Kabhi loop ko beech mein rokna hota hai, kabhi current round skip karna hota hai, kabhi function se value return karni hoti hai. Ye statements loop ko smart banate hain.

break

Loop ko turant stop. Jaise correct password milte hi attempts loop bandh.

continue

Current iteration skip. Jaise absent student ko skip karke next student.

return

Function ko stop karke value wapas. Loop ke andar match milte hi answer return.

labels

Nested loops mein specific outer loop break/continue. Rare but interview mein useful.

for (let i = 1; i <= 8; i++) {
  if (i === 3) continue;
  if (i === 6) break;
  console.log(i);
}
outerLoop:
for (let row = 1; row <= 3; row++) {
  for (let col = 1; col <= 3; col++) {
    if (row === 2 && col === 2) {
      break outerLoop;
    }
    console.log(row, col);
  }
}
I. Modern Array Loops

forEach, map, filter, reduce 🧠

Ye methods arrays ke saath daily use hote hain. Inhe "loop-like methods" bol sakte hain kyunki ye array ke har item par kaam karte hain.

Method Use Return Real-life
forEach Har item par action undefined Har comment display karo
map New transformed array New array Prices mein GST add karo
filter Condition matching items New array Passed students nikalo
reduce Single result Any value Cart total calculate karo 
let prices = [100, 250, 80, 500];

prices.forEach(price => console.log(price));

let withGst = prices.map(price => price * 1.18);
let expensive = prices.filter(price => price > 100);
let total = prices.reduce((sum, price) => sum + price, 0);
J. Advanced Basics

Advanced Loop Concepts ⚙️

Infinite Loops

Condition kabhi false na ho to loop forever. Always update counter and test condition carefully.

Performance

Huge arrays mein unnecessary nested loops avoid karo. DOM updates ko batch karo.

DOM Loops

Buttons, cards, rows render karne ke liye array loop + DOM creation common pattern hai.

Event Loop Intro

JavaScript async tasks ko event loop se manage karta hai. Ye `for loop` wala loop nahi, runtime system ka loop hai.

Async Loops

`for...of` ke andar `await` use kar sakte ho jab tasks sequence mein chalane ho.

DOM Performance Tip

Loop ke andar baar-baar `innerHTML +=` slow ho sakta hai. Pehle string/fragment banao, phir ek baar render karo.

// DOM loop example
let users = ["Aman", "Sara", "Neha"];
let html = "";

for (let user of users) {
  html += `<li>${user}</li>`;
}

list.innerHTML = html;

    Interview Prep

    Interview Questions, Tricky Points & Best Practices 💼

    `for...in` keys deta hai, mostly objects ke liye. `for...of` values deta hai, mostly arrays/strings ke liye.

    `map` new array return karta hai. `forEach` sirf action perform karta hai aur `undefined` return karta hai.

    Condition clearly false hone layak rakho, counter update karo, aur huge loops mein exit condition/break plan karo.

    Jab outer 10,000 aur inner 10,000 ho, total 100 million operations ho sakte hain. Better data structures use karo.

    Tricky Questions

    `var` inside loop closure issue, `break` vs `return`, array length change during loop, async `forEach` with `await` confusion.
